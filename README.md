# Beecrowd 1101 - Sequência de Números e Soma

## Descrição
Programa desenvolvido em Java para ler pares de números inteiros, imprimir a sequência do menor até o maior valor e calcular a soma dos números de cada sequência.

## Linguagem
Java

## Entrada
O programa recebe pares de números inteiros M e N. A execução termina quando um dos valores for menor ou igual a zero.

## Saída
Imprime os números inteiros em ordem crescente e a soma de todos os valores da sequência, incluindo o menor e o maior número.
